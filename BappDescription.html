Asset Saver adds a context menu item for saving response bodies to disk. It writes the raw bytes of the response, avoiding the encoding issues that can occur when copying or saving binary data through other means.

Features

  • Adds a Save Asset context menu item to HTTP History entries and to the request/response viewer across tools such as Proxy, Repeater, and Logger.
  • Writes the unmodified raw bytes of the response body, preserving binary assets like images, archives, fonts, and media files.
  • Pre-fills the suggested filename from the response.

Usage

  1. Right-click an item that has a response, either in HTTP History or in a request/response viewer.
  2. Select Save Asset from the context menu.
  3. Confirm or edit the suggested filename in the file chooser and choose a destination to write the asset.
